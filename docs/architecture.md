# Архитектура Android-приложения

## Компоненты

Исходники: `android/app/src/main/java/com/qq/knitushka/`.

| Компонент | Ответственность |
| --- | --- |
| `MainActivity` | Compose, жизненный цикл, сигнал о восстановлении сети |
| `ScheduleViewModel` | Выбранная группа, дата, ошибки, загрузка и предпросмотр соседних недель |
| `ui/` | Material 3, темы, календарь, дневной и недельный pager |
| `data/ScheduleParser` | Преобразование HTML в институты, группы и занятия |
| `data/ScheduleRepository` | OkHttp, валидация ответа, Room и DataStore |
| `data/*java` | Room entity, DAO и database; Java annotation processor без KSP |
| `KnituApplication` | Репозиторий приложения и WorkManager |

## Источник данных

- `https://www.kstu.ru/www_GFgrid.jsp` — институты и группы, параметр `f`.
- `https://www.kstu.ru/www_Ggrid.jsp?f=…&g=…&d=…` — недельное расписание группы.

Парсер читает основную недельную HTML-таблицу и не добавляет её мобильные дубликаты. Чётность берётся из источника, а не вычисляется по календарному номеру недели. Разметка внешнего сайта может меняться, поэтому ошибка распознавания не считается днём без занятий.

В одном временном слоте бывают повторяющиеся записи с разными сроками действия или пропущенными полями. Однозначные дубли объединяются с сохранением заполненных полей. Записи с явно разными аудиториями, преподавателями или подгруппами остаются отдельными. Совпадение предмета в двух последовательных временных слотах не является дублем.

## Offline-first

Room хранит валидированные HTML-ответы и время проверки по ключу группы и недели. UI сначала получает сохранённую версию, затем репозиторий проверяет источник. Запись нового ответа производится только после успешного парсинга; сбой сети или сайта не затирает кэш.

DataStore хранит выбранную группу и тему. Предзагрузка охватывает предыдущую, текущую и две следующие недели; доступность зависит от успешного ответа сайта. Фоновая проверка запланирована через WorkManager раз в 6 часов с требованием сети; точное время выполнения определяет Android. Частота обычных запросов ограничена 15-минутным TTL, ручная проверка обходит TTL.

Отдельное расписание экзаменов пока не подключено. Собственного API-сервера, авторизации и синхронизации между устройствами нет.

## Тестовые данные и внешние права

`android/app/src/test/resources/fixtures/` содержит снимки публичных HTML-страниц для воспроизводимых тестов. Они не являются исходниками университета, не используются как демоданные рабочего приложения и не считаются отдельно лицензированными под MIT. Их источник — kstu.ru; права на внешнее содержимое остаются у правообладателей.
