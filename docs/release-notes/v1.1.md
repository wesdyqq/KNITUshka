# КНИТУшка 1.1

- Обновлён виджет: крупная дата, жирные номера пар, залитые индикаторы дней и компактные стрелки с прежней областью нажатия.
- В приложении время занятий стало жирнее и контрастнее.
- Стрелка возврата на сегодня плавно появляется поверх дней, не сдвигая их. Переходы по кнопкам анимированы.
- Обновлены README и скриншоты.

Виджет переключает даты кнопками. Нажатие на расписание открывает выбранный день в приложении.

Скачай `KNITUshka-v1.1.apk` и установи поверх предыдущего релиза. Идентификатор `com.qq.knitushka` и production-подпись сохраняются; удалять старую версию не нужно.
